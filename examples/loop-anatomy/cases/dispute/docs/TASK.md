A customer disputes a card transaction. Decide whether we give provisional
credit, for how much, by when, and whether the case must be escalated.
Then write the decision memo to decision.md in this folder.

Use only the documents in this folder. The memo must state the amount, the
date by which the credit must be posted, the policy clause and network
reason code you relied on, whether escalation is required and why, and
the documents you used. Be exact with numbers and dates.
