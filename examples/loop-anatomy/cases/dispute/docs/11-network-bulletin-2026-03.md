# Meridian network bulletin 2026-03 (invented for this demo)

Issued 11 March 2026.

Compromised terminal id HARB-77120 at acquirer Harbor Acquiring processed a
batch of card-not-present transactions on 9 March 2026 for merchant
Northgate Sports Ltd using card numbers obtained from a third-party data
leak. Issuers should treat 9 March 2026 card-not-present transactions for
this merchant reported by cardholders as unauthorized (reason code 10.4)
without requiring a signed cardholder statement. Transactions on other
dates for this merchant are not affected.
